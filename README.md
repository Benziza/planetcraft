# Planetcraft

Explore a universe of blocks, inspired by Minecraft.

![Earth in day and night, followed by the Mars 404 screen](.github/assets/planetcraft-demo.gif)

Choose a planet and start exploring. Earth and Mars are ready: give them a spin, discover their landscapes, and switch between day and night. Mars adds red dunes, craters, volcanic highlands, canyons, polar ice caps, and optional dust haze. Its terrain is a playful interpretation, not a geographic map.

The other planets are still waiting for their first blocks.

[Explore Planetcraft](https://benziza.github.io/planetcraft/)

To preview locally, run `npm ci` and `npm run dev`, then open `http://localhost:5173/#/mars`.
